Agent work with users, revenue stakes, and receipts.

In product
agents users touch, at Cloaked

I built autonomous LangChain agents that change passwords, log in, and manage email on users’ behalf. They became a core fundraising narrative and powered an AI onboarding experience that measurably boosted adoption and retention.

In the repo
agents that write code

At Block Party I designed and built the framework behind the company’s internal AI coding bots. I also maintain Fountain, a developer platform for running fleets of sandboxed coding agents, itself built by the agents it orchestrates. Fountain ships under BinaryBourbon, the GitHub identity my agent fleet works under. I set the roadmap and review the work.

$400K
pre-seed for an agent-native SaaS

I cofounded Ravi, where AI agents manage their own accounts, secrets, and 2FA. It raised a $400K pre-seed from South Park Commons and grew to hundreds of users, with the instrumented v1’s real usage data carrying the pitch.

Protocol
MCP and A2A in the wild

I am a member of the MCP Hosting Working Group, publish MCP servers, and contributed to the Dart MCP SDK. This site practices what I pitch. ai.jakegaylor.com serves an A2A agent card and an MCP server, so your screening agent can interview me directly.

For the keyword scanners: LangChain, MCP, A2A, the Dart MCP SDK, Claude Code, Cursor, sandboxed execution, Python, TypeScript. Every one of them attached to shipped agent work above or on the resume.

The day-2 receipts

Agents with real identities

My fleet works under its own GitHub account with its own scoped credentials. Delegation only works when an agent can hold keys you can revoke in one move, and mine do.

Sandboxes and review gates

Fountain runs its agents in sandboxes behind review gates. Scaling from one agent to a fleet is an operations problem, and I run those operations daily on my own work.

Measured like a product

Agent features earn trust with numbers. Ravi’s instrumented v1 carried its fundraise, and Cloaked’s agents lifted onboarding retention measurably.
