The day-2 receipts

Measured, so it counts

At Cloaked I built the product analytics stack that made data-driven decisions normal across the company. Measurement is why I can say 30x instead of “a lot faster.”

Fast is safe when response is rehearsed

At Cardfree I replaced ad-hoc Slack firefighting with a PCI-compliant incident response program. Shipping on demand is only comfortable when a bad deploy has a known playbook.

I still ship this way daily

Every deploy to my homelab is a git commit. Flux CD reconciles it, Prometheus watches it, and rollback is a git revert. The newest pipeline I run went live in my house.
